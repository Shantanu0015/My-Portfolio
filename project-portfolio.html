Personal Portfolio

A multi-page, fully responsive portfolio website designed to showcase my skills, projects, and services with a modern, dark-themed aesthetic and smooth animations.

Project Overview

Multi-Page Architecture

Built with dedicated pages for Services, Skills, Education, Experience, and Contact to provide a clean, organized user journey.

Responsive Design

Fluid grids and media queries ensure the site looks and functions perfectly across all devices, from large monitors to mobile phones.

Modern Dark Theme

Designed with a sleek dark mode aesthetic using a custom black and red (#b74b4b) color palette for a premium, professional feel.

CSS Animations

Implemented custom CSS animations, hover effects, glowing elements, and interactive components to make the interface feel alive.

Clean Codebase

Written from scratch using semantic HTML5 and vanilla CSS3 with a focus on maintainability, readability, and performance.

SEO & Performance

Optimized with proper meta tags, semantic structure, and compressed assets for fast loading times and better search engine visibility.
