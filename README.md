# Personal Portfolio 🚀

**🔴 Live Demo:** [View Live Website](https://your-live-link-here.vercel.app/)

Welcome to my personal portfolio repository! This is a multi-page, fully responsive portfolio website built to showcase my skills, projects, and services as a Web Developer.

## 🌟 Features
- **Multi-Page Architecture**: Dedicated pages for Home, Services, Skills, Education, Experience, and Contact.
- **Modern Dark Theme**: A sleek, Netflix-inspired dark mode aesthetic for a premium feel.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Smooth Animations**: Custom CSS animations and interactive hover effects.
- **Project Showcase**: Detailed case studies for my projects including StudyPilot AI, ScamShield, AES File Encryption, and a Web-Based Quiz App.

## 🛠️ Technologies Used
- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom styling, flexbox/grid layouts, and animations.
- **JavaScript**: Interactive elements and DOM manipulation.
- **FontAwesome**: Icons for UI enhancement.

## 📂 Project Structure
- `index.html` - Main landing page
- `services.html` & `service-*.html` - Offered services and detailed service pages
- `skills.html` - Technical and professional skills
- `education.html` - Academic background
- `experience.html` & `project-*.html` - Projects showcase and individual project pages
- `contact.html` - Contact form and links
- `style.css` - Global stylesheet
